LanDrop · 局域网快传 v1.0
====================================

同一 Wi-Fi 下，在几台 Windows 电脑之间直接传文件。
免安装，文件只在局域网内传输，不经过微信或互联网。


一、准备
------------------------------------
1. 每台电脑需要 Windows 10 / 11（系统自带 .NET Framework 4.8）。
2. 把 LanDrop.exe 复制到每台电脑，建议放在固定位置，例如 D:\LanDrop\。
3. 不需要安装 Python、Node.js 或其他软件。


二、第一次运行
------------------------------------
1. 双击 LanDrop.exe。
2. 如果 Windows 提示“Windows 已保护你的电脑”：
   点“更多信息” → “仍要运行”。
3. 如果 Windows 防火墙弹出提示：
   勾选“专用网络”，点“允许访问”。这一步必须允许，否则别的电脑连不上。
4. 浏览器会自动打开 http://127.0.0.1:52180/
   右下角托盘会出现 LanDrop 图标。
5. 页面右上角显示“连接码”，例如 ABCD-EFGH。

提示：
- 如果 52180 端口被占用，程序会自动换用 52181、52182……
  实际端口以“设置”里显示的为准。
- 关闭浏览器后程序仍在托盘运行，传输不会中断。
  要退出：右键托盘图标 → “退出 LanDrop”。


三、连接另一台电脑
------------------------------------
假设 A 电脑已经打开 LanDrop，在 B 电脑上：

1. 点右侧“对方电脑”区域的“添加设备”。
2. 在“附近设备”里选中 A 电脑。
3. 输入 A 电脑右上角的连接码。
4. 点“连接”。

如果附近设备列表是空的：
1. 切换到“手动输入 IP”。
2. IP 填 A 电脑顶部显示的地址，例如 192.168.1.23。
3. 端口填 A 电脑“设置”里显示的端口，默认 52180。
4. 输入连接码，点“连接”。

配对一次后，B 会记住 A；以后打开会自动选中上次的设备。


四、传文件
------------------------------------
左边是“本机”，右边是“对方电脑”。

1. 双击文件夹进入；用磁盘下拉框切换磁盘。
2. 单击文件/文件夹选中；按住 Ctrl 可多选，也可以勾选复选框。
3. 选中左侧项目 → 点“传到对面 →”。
4. 选中右侧项目 → 点“← 下载到本机”。
5. 文件夹会连同子文件夹一起传输。
6. 底部“传输队列”显示进度、速度、当前文件。
   可以展开、取消任务、清除已完成。

同名文件不会覆盖：
目标位置已有同名文件时，会自动变成“文件名 (1).扩展名”。


五、常见问题
------------------------------------
1. 对方设备不出现
   - 两台电脑都打开了 LanDrop；
   - 连的是同一个 Wi-Fi / 同一网段；
   - Windows 防火墙允许了“专用网络”；
   - 路由器没有开启 AP 隔离 / 访客网络隔离；
   - 仍不行就“手动输入 IP”。

2. 提示无法连接 / 超时
   - 在命令提示符里 ping 对方 IP，确认能通；
   - 确认对方 LanDrop 还在托盘运行；
   - 网络类型设为“专用网络”，不要用“公用网络”；
   - 检查安全软件是否拦截；
   - 端口可能不是 52180，以对方设置里显示的为准。

3. 传输失败：没有权限
   - 不要传到 C:\Program Files、C:\Windows 等系统目录；
   - 换到桌面、文档或用户目录；
   - 检查对方磁盘空间；
   - 检查文件是否被 Excel/Word/播放器独占打开。

4. 速度慢
   - 优先 5 GHz Wi-Fi，条件允许用网线；
   - 大量小文件比单个大文件慢，属正常现象；
   - 传输时避免同时看视频/下载。


六、安全提醒
------------------------------------
连接码相当于文件访问钥匙。
拿到连接码的人可以浏览和修改你允许访问的文件。
请只在可信的家庭局域网使用，不要把连接码发给陌生人；
在公共 Wi-Fi 下建议退出 LanDrop。


七、数据和卸载
------------------------------------
配置和日志位置：
%APPDATA%\LanDrop\

landrop.log 是运行日志，排错时可以查看。

卸载步骤：
1. 右键托盘图标 → 退出 LanDrop；
2. 设置里关闭“开机自动启动”；
3. 删除 LanDrop.exe；
4. 如需清除配对信息，再删除 %APPDATA%\LanDrop 文件夹。

注意：删除 config.json 会重置连接码和所有配对设备，需要重新配对。
